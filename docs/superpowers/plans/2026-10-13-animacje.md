# Zaklęty Ogród — animacje: plan wdrożenia

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Płynny ruch gracza, animowane przedmioty, stopniowe odkrywanie mgły, cienie chmur, świetliki i liście oraz płynne przejścia ekranów — bez zmiany zasad gry, z poszanowaniem `prefers-reduced-motion`.

**Architecture:** Nowy moduł `src/animacje.js` zawiera wyłącznie czyste funkcje (czas i `rng` podawane z zewnątrz). `src/render.js` dzieli rysowanie na część statyczną (`rysujPlansze` — rysowana raz do warstwy w pamięci), ruchomą (`rysujKlatke`) i tło animowane (`rysujTloAnimowane`); siatka pól jest zapamiętywana na labirynt. `src/main.js` prowadzi pętlę `requestAnimationFrame`, trzyma stan animacji `anim` i wyzwala efekty po zdarzeniach z `ruch()`. Logika gry (`game.js`, `maze.js`, `baza.js`) bez zmian.

**Tech Stack:** HTML + CSS + JavaScript (ES modules), Canvas 2D, `requestAnimationFrame`, `matchMedia`, `node --test` (Node ≥ 18), Playwright + Chromium headless do sprawdzenia w przeglądarce.

**Spec:** `docs/superpowers/specs/2026-10-13-animacje-design.md`

**Odstępstwo od specyfikacji:** nakładki (§6) dostają tylko animację pojawiania (CSS `@keyframes`, 200 ms), bez animowanego znikania. Znikanie z opóźnionym `hidden` wymagałoby timerów ścigających się z szybkimi klawiszami (Enter tuż po Esc), a płynność przejścia do gry i tak zapewnia animacja wejścia planszy (300 ms). Zadanie 5 nanosi to na specyfikację.

## Global Constraints

- Bez bibliotek i bundlera; testy tylko `node --test`.
- `src/animacje.js` — bez DOM, `window`, `performance`, `Math.random`: czas (ms) i `rng` zawsze z argumentów.
- Czasy: ruch gracza 120 ms (`easeOutCubic`), odkrycie mgły 300 ms, przyciemnienie 200 ms, iskry 500 ms, rozbłysk 600 ms, wejście planszy 300 ms, nakładki 200 ms.
- Odbicie od ściany: 4% boku pola. Unoszenie klucza: 6% boku pola, okres 2 s; błysk 400 ms co 3 s. Puls drzwi: okres 1,5 s. Iskier: 14. Świetliki: 8–16. Liście: 5. Chmury: 4, łączne krycie ≤ 0,25.
- Funkcje rysujące nie mogą trwale zmieniać `ctx.globalAlpha` — mnożą bieżącą wartość i ją przywracają (wejście planszy ustawia `globalAlpha` przed rysowaniem).
- `prefers-reduced-motion: reduce` → brak pętli, brak interpolacji, efektów i tła animowanego; klatka rysowana tylko po zdarzeniach.
- Logika gry, zapis do Supabase i istniejące testy bez zmian zachowania.
- Komentarze i identyfikatory po polsku, jak w istniejącym kodzie.

## Review Focus

1. **Przytrzymana strzałka / szybkie naciśnięcia** → gracz płynnie biegnie, nigdy nie „skacze wstecz” ani nie zostaje w tyle za logiką; odbicie w trakcie ruchu nie przerywa ruchu. Test: Zadanie 1.
2. **`globalAlpha` po klatce** → wraca do wartości sprzed klatki (inaczej wejście planszy albo kolejne klatki „blakną”). Test: Zadanie 3.
3. **Nowy labirynt (`R`, nowy poziom, wznowienie)** → przejścia mgły, świetliki i warstwa statyczna nie pochodzą ze starego labiryntu (różne rozmiary tablic). Test: Zadanie 1 (`aktualizujMgle` z tablicą innej długości) + Zadanie 3 (pamięć pól per labirynt).
4. **Klawisze w trakcie rozbłysku ukończenia** → ignorowane; zapis wyniku i stanu idzie od razu, nie po animacji. Sprawdzenie: Zadanie 4 (Playwright).
5. **`prefers-reduced-motion: reduce`** → gra w pełni działa, bez pętli i bez animacji. Sprawdzenie: Zadanie 4 (Playwright z `reducedMotion: 'reduce'`).

// Czyste funkcje animacji: łagodzenie, ruch gracza, przejścia mgły, cząsteczki i efekty.
// Bez DOM — czas (ms, np. z performance.now()) i losowość (`rng`) zawsze podawane z zewnątrz.

export const CZAS_RUCHU = 120;
export const CZAS_ODKRYCIA = 300;
export const CZAS_PRZYCIEMNIENIA = 200;
export const CZAS_ISKIER = 500;
export const CZAS_ROZBLYSKU = 600;
export const CZAS_WEJSCIA = 300;
/** Wychylenie odbicia od ściany jako część boku pola. */
export const ODBICIE = 0.04;

export const easeOutCubic = (t) => 1 - (1 - t) ** 3;
export const easeInOutSine = (t) => -(Math.cos(Math.PI * t) - 1) / 2;

/** Postęp 0..1 animacji trwającej `trwanie` ms od chwili `od`. */
export function postep(od, czas, trwanie) {
  if (!(trwanie > 0)) return 1;
  return Math.min(1, Math.max(0, (czas - od) / trwanie));
}

// --- Ruch gracza (pozycje w jednostkach pól, mogą być ułamkowe) ---

/** Gracz stojący na polu `poz`. */
export function ruchStaly(poz) {
  return { od: { x: poz.x, y: poz.y }, do: { x: poz.x, y: poz.y }, start: 0, trwanie: 0, odbicie: null };
}

/** Wyświetlana pozycja gracza w chwili `czas`. */
export function pozycjaGracza(ruch, czas) {
  const p = postep(ruch.start, czas, ruch.trwanie);
  if (ruch.odbicie) {
    const s = Math.sin(Math.PI * p) * ODBICIE;
    return { x: ruch.do.x + ruch.odbicie.dx * s, y: ruch.do.y + ruch.odbicie.dy * s };
  }
  const t = easeOutCubic(p);
  return { x: ruch.od.x + (ruch.do.x - ruch.od.x) * t, y: ruch.od.y + (ruch.do.y - ruch.od.y) * t };
}

/** Przejście do pola `cel` od bieżącej wyświetlanej pozycji — przerwany ruch nie skacze. */
export function nowyRuch(poprzedni, cel, czas, ograniczony = false) {
  if (ograniczony) return ruchStaly(cel);
  return {
    od: pozycjaGracza(poprzedni, czas),
    do: { x: cel.x, y: cel.y },
    start: czas,
    trwanie: CZAS_RUCHU,
    odbicie: null,
  };
}

/** Odbicie od ściany w kierunku {dx, dy}: wychylenie i powrót. Trwający ruch nie jest przerywany. */
export function odbicie(poprzedni, kierunek, czas, ograniczony = false) {
  const wRuchu = !poprzedni.odbicie && postep(poprzedni.start, czas, poprzedni.trwanie) < 1;
  if (ograniczony || wRuchu) return poprzedni;
  return {
    od: { ...poprzedni.do },
    do: { ...poprzedni.do },
    start: czas,
    trwanie: CZAS_RUCHU,
    odbicie: { dx: kierunek.dx, dy: kierunek.dy },
  };
}

// --- Mgła: przejścia krycia pól ---

const KRYCIE = {
  nieodkryte: { mgla: 1, cien: 0 },
  odkryte: { mgla: 0, cien: 1 },
  widoczne: { mgla: 0, cien: 0 },
};

/** Krycie pola w chwili `czas`: części pełnej mgły i pełnego przyciemnienia (0..1). */
export function kryciePola(p, czas) {
  const cel = KRYCIE[p.stan];
  const trwanie = cel.mgla < p.z.mgla ? CZAS_ODKRYCIA : CZAS_PRZYCIEMNIENIA;
  const t = postep(p.od, czas, trwanie);
  return { mgla: p.z.mgla + (cel.mgla - p.z.mgla) * t, cien: p.z.cien + (cel.cien - p.z.cien) * t };
}

/**
 * Przejścia mgły po zmianie stanów pól. `przejscia` — poprzednia tablica albo null (brak historii — bez przejść;
 * tablica innej długości pochodzi z innego labiryntu i jest pomijana). Pole o zmienionym stanie przechodzi
 * od bieżącego krycia do nowego od chwili `czas`.
 */
export function aktualizujMgle(przejscia, stany, czas, ograniczony = false) {
  const historia = przejscia && przejscia.length === stany.length ? przejscia : null;
  return stany.map((stan, k) => {
    const p = historia?.[k];
    if (!p || ograniczony) return { stan, od: -Infinity, z: KRYCIE[stan] };
    if (p.stan === stan) return p;
    return { stan, od: czas, z: kryciePola(p, czas) };
  });
}
```

/** Iskry wylatujące z pola (x, y). */
export function iskry(x, y, rng, czas, ile = 14) {
  return Array.from({ length: ile }, () => {
    const kat = rng() * Math.PI * 2;
    const v = 1 + rng() * 1.5; // pól na sekundę
    return { x, y, vx: Math.cos(kat) * v, vy: Math.sin(kat) * v, start: czas };
  });
}

/** Położenie i krycie iskry; null po CZAS_ISKIER. */
export function stanIskry(iskra, czas) {
  const p = postep(iskra.start, czas, CZAS_ISKIER);
  if (p >= 1) return null;
  const s = Math.max(0, czas - iskra.start) / 1000;
  return { x: iskra.x + iskra.vx * s, y: iskra.y + iskra.vy * s, alfa: 1 - p };
}

/** 8–16 świetlików nad losowymi polami żywopłotu (`pola` z kafle()). */
export function swietliki(pola, rng) {
  const kandydaci = [];
  for (let k = 0; k < pola.length; k++) if (pola[k].zywoplot) kandydaci.push(k);
  const ile = Math.min(16, Math.max(8, Math.round(kandydaci.length / 60)));
  return Array.from({ length: ile }, () => ({
    k: kandydaci[Math.floor(rng() * kandydaci.length)],
    faza: rng() * Math.PI * 2,

    promien: 0.3 + rng() * 0.7,
  }));
}

  return {
    dx: Math.cos(t * 0.5) * s.promien,
    dy: Math.sin(t * 0.7) * s.promien,

}

export function pozycjaChmury(c, czas, szer) {
  const droga = szer + 2 * c.r;
  const x = ((((c.x0 + (c.predkosc * czas) / 1000) % droga) + droga) % droga) - c.r;
  return { x, y: c.y, r: c.r };
}

const KOLORY_LISCI = ['#c9a227', '#b5651d', '#8a5a2b', '#d4a017'];

/**
 * Liście dryfujące nad lasem. `plansza` = {x, y, szer, wys} w px — liście tylko w pasach po jej bokach
 * (pas węższy niż 24 px — bez liści); null — cała szerokość (ekran startowy).
 * Kołysanie mieści się w pasie z marginesem 6 px.
 */
export function liscie(szer, wys, plansza, rng, ile = 5) {
  const pasy = plansza
    ? [[0, plansza.x], [plansza.x + plansza.szer, szer]].filter(([a, b]) => b - a >= 24)
    : [[0, szer]];
  if (!pasy.length) return [];
  return Array.from({ length: ile }, () => {
    const [a, b] = pasy[Math.floor(rng() * pasy.length)];
    const pol = (b - a) / 2;
    const amp = Math.min(12, pol - 6);
    return {
      srodek: a + pol + (rng() * 2 - 1) * (pol - 6 - amp),
      amp,
      y0: rng() * wys,
      predkosc: 15 + rng() * 15,
      faza: rng() * Math.PI * 2,
      kolor: KOLORY_LISCI[Math.floor(rng() * KOLORY_LISCI.length)],
    };
  });
}

/** Liść opada, kołysze się na boki i obraca; po wyjściu na dole wraca na górę. */
export function pozycjaLiscia(l, czas, wys) {
  const s = czas / 1000;
  const droga = wys + 40;
  const y = ((((l.y0 + l.predkosc * s) % droga) + droga) % droga) - 20;
  return { x: l.srodek + Math.sin(s * 1.3 + l.faza) * l.amp, y, kat: Math.sin(s * 2 + l.faza) * 0.6 };
}

}

const KOLORY = {
  las: '#0d1410',
  zwir: '#b8a27f',
  zywoplot: '#2f4a2a',
  cien: 'rgba(0, 0, 0, 0.6)',
  mgla: '#07090d',
  przyciemnienie: 'rgba(7, 9, 13, 0.55)',
  obrys: '#0b0d10',
  gracz: '#4fc3ff',
  klucz: '#ffd23f',
  blysk: '#fffbe0',
  drzwiZamkniete: '#ff6b6b',
  drzwiOtwarte: '#5ee08a',
  swietlik: '#f6f7a8',
  iskra: '#ffd23f',
  rozblysk: '#e9ffe9',
  chmura: '#000000',
};

/** Ile komórek (ścieżka + pas żywopłotu) obejmuje jeden kafel tekstury żwiru i żywopłotu. */
const KOMOREK_NA_KAFEL = 3;
/** Bok kafla tekstury lasu w px CSS — stały, żeby tło nie zmieniało skali między poziomami. */
const KAFEL_LASU_PX = 256;
/** Warstwy cienia chmury: [skala promienia, krycie] — razem ≤ 0,25. */
const WARSTWY_CHMURY = [[1, 0.06], [0.75, 0.07], [0.5, 0.08]];

const gruboscObrysu = (kom) => Math.max(1, kom * 0.06);

/** Ustawia rozmiar canvasu pod okno z uwzględnieniem devicePixelRatio. Zwraca kontekst 2D. */
export function dopasujCanvas(canvas, szerokoscCss, wysokoscCss, dpr) {
  canvas.style.width = `${szerokoscCss}px`;
  canvas.style.height = `${wysokoscCss}px`;
  canvas.width = Math.round(szerokoscCss * dpr);
  canvas.height = Math.round(wysokoscCss * dpr);
  const ctx = canvas.getContext('2d');
  ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  return ctx;
}

/** Wzór z tekstury, w którym jeden kafel ma `bokPx`; bez tekstury — kolor zastępczy. */
function wypelnienie(ctx, obraz, bokPx, kolor) {
  if (!obraz) return kolor;
  const wzor = ctx.createPattern(obraz, 'repeat');
  const skala = bokPx / obraz.width;
  wzor.setTransform({ a: skala, b: 0, c: 0, d: skala, e: 0, f: 0 });
  return wzor;
}

/** Wypełnia `styl` z kryciem `alfa` względem bieżącego globalAlpha (i je przywraca). */
function zKryciem(ctx, alfa, rysowanie) {
  const poprzednie = ctx.globalAlpha;
  ctx.globalAlpha = poprzednie * alfa;
  rysowanie();
  ctx.globalAlpha = poprzednie;
}

const PAMIEC_POL = new WeakMap();

/** Pola siatki labiryntu — liczone raz na labirynt (labirynt się nie zmienia; `R` tworzy nowy obiekt). */
export function polaPlanszy(labirynt) {
  let pola = PAMIEC_POL.get(labirynt);
  if (!pola) {
    pola = kafle(labirynt);
    PAMIEC_POL.set(labirynt, pola);
  }
  return pola;
}

/** Stan mgły każdego pola siatki dla bieżącego stanu gry. */
export function stanyPol(stan) {
  return polaPlanszy(stan.labirynt).map((p) => stanPola(p.sasiedzi, stan.odkryte, stan.widoczne));
}

/** Geometria planszy w obszarze: układ, lewy górny róg pola (także dla ułamkowych pozycji) i prostokąt pola siatki. */
function geometria(labirynt, szer, wys) {
  const u = uklad(labirynt, szer, wys);
  return {
    u,
    komX: (x) => u.ox + u.sc + x * (u.kom + u.sc),
    komY: (y) => u.oy + u.sc + y * (u.kom + u.sc),
    prostokat: (p) => {
      const a = pas(u, p.gx, u.ox);
      const b = pas(u, p.gy, u.oy);
      return [a.start, b.start, a.dl, b.dl];
    },
  };
}

function wypelnijPola(ctx, pola, prostokat, warunek, styl) {
  ctx.beginPath();
  for (let k = 0; k < pola.length; k++) if (warunek(k)) ctx.rect(...prostokat(pola[k]));
  ctx.fillStyle = styl;
  ctx.fill();
}

function kolo(ctx, x, y, r) {
  ctx.beginPath();
  ctx.arc(x, y, r, 0, Math.PI * 2);
  ctx.fill();
}

/** Las na całym obszarze — tło pod planszą i ekranami. */
export function rysujTlo(ctx, szerokoscCss, wysokoscCss, tekstury) {
  ctx.fillStyle = wypelnienie(ctx, tekstury.las, KAFEL_LASU_PX, KOLORY.las);
  ctx.fillRect(0, 0, szerokoscCss, wysokoscCss);
}

/** Cienie chmur i liście nad lasem (rysowane pod planszą). */
export function rysujTloAnimowane(ctx, szer, wys, chmury, liscie, czas) {
  ctx.fillStyle = KOLORY.chmura;
  for (const c of chmury) {
    const { x, y, r } = pozycjaChmury(c, czas, szer);
    for (const [skala, alfa] of WARSTWY_CHMURY) {
      zKryciem(ctx, alfa, () => {
        ctx.beginPath();
        ctx.ellipse(x, y, r * skala, r * skala * 0.6, 0, 0, Math.PI * 2);
        ctx.fill();
      });
    }
  }
  for (const l of liscie) {
    const { x, y, kat } = pozycjaLiscia(l, czas, wys);
    ctx.fillStyle = l.kolor;
    ctx.beginPath();
    ctx.ellipse(x, y, 5, 2.5, kat, 0, Math.PI * 2);
    ctx.fill();
  }
}

/** Statyczna część planszy: cień polany, żwir, żywopłot — rysowana raz do warstwy w pamięci. */
export function rysujPlansze(ctx, stan, szer, wys, tekstury) {
  const { u, prostokat } = geometria(stan.labirynt, szer, wys);
  const pola = polaPlanszy(stan.labirynt);
  const bokKafla = KOMOREK_NA_KAFEL * (u.kom + u.sc);

  // Polana: żwir pod całą planszą, z miękkim cieniem na las
  ctx.save();
  ctx.shadowColor = KOLORY.cien;
  ctx.shadowBlur = Math.max(8, u.sc * 2);
  ctx.fillStyle = wypelnienie(ctx, tekstury.zwir, bokKafla, KOLORY.zwir);
  ctx.fillRect(u.ox, u.oy, u.szer, u.wys);
  ctx.restore();

  // Żywopłot
  wypelnijPola(ctx, pola, prostokat, (k) => pola[k].zywoplot, wypelnienie(ctx, tekstury.zywoplot, bokKafla, KOLORY.zywoplot));
}

/** Ruchoma część planszy w chwili `czas`: drzwi, klucz, mgła z przejściami, świetliki, gracz, iskry, rozbłysk. */
export function rysujKlatke(ctx, stan, szer, wys, anim, czas) {
  const { labirynt, odkryte } = stan;
  const { u, komX, komY, prostokat } = geometria(labirynt, szer, wys);
  const pola = polaPlanszy(labirynt);
  const ruchome = !anim.ograniczony;

  // Drzwi i klucz — tylko na odkrytych polach
  const odkrytePole = (p) => odkryte.has(indeks(labirynt, p.x, p.y));
  if (odkrytePole(stan.wyjscie)) {
    rysujDrzwi(ctx, komX(stan.wyjscie.x), komY(stan.wyjscie.y), u.kom, stan.maKlucz, ruchome ? pulsDrzwi(czas) : 0);
  }
  if (!stan.maKlucz && odkrytePole(stan.klucz)) {
    const dy = ruchome ? unoszenieKlucza(czas) * u.kom : 0;
    rysujKlucz(ctx, komX(stan.klucz.x), komY(stan.klucz.y) + dy, u.kom, ruchome ? blyskKlucza(czas) : null);
  }

  // Mgła i przyciemnienie: pola w pełni zakryte jedną ścieżką, pola w trakcie przejścia osobno z kryciem
  const przejscia = anim.mgla ?? aktualizujMgle(null, stanyPol(stan), czas);
  const krycia = przejscia.map((p) => kryciePola(p, czas));
  wypelnijPola(ctx, pola, prostokat, (k) => krycia[k].mgla >= 0.999, KOLORY.mgla);
  wypelnijPola(ctx, pola, prostokat, (k) => krycia[k].cien >= 0.999, KOLORY.przyciemnienie);
  for (let k = 0; k < pola.length; k++) {
    const { mgla, cien } = krycia[k];
    for (const [alfa, styl] of [[mgla, KOLORY.mgla], [cien, KOLORY.przyciemnienie]]) {
      if (alfa <= 0.001 || alfa >= 0.999) continue;
      zKryciem(ctx, alfa, () => {
        ctx.fillStyle = styl;
        ctx.fillRect(...prostokat(pola[k]));
      });
    }
  }

  // Świetliki nad odkrytym żywopłotem
  ctx.fillStyle = KOLORY.swietlik;
  const r = Math.max(1.5, u.kom * 0.06);
  for (const s of anim.swietliki) {
    if (krycia[s.k].mgla > 0.5) continue;
    const { dx, dy, alfa } = stanSwietlika(s, czas);
    const [x, y, w, h] = prostokat(pola[s.k]);
    const cx = x + w / 2 + dx * u.kom;
    const cy = y + h / 2 + dy * u.kom;
    zKryciem(ctx, alfa * 0.25, () => kolo(ctx, cx, cy, r * 3));
    zKryciem(ctx, alfa, () => kolo(ctx, cx, cy, r));
  }

  // Gracz — koło z obrysem, w wyświetlanej (interpolowanej) pozycji
  const g = pozycjaGracza(anim.ruch, czas);
  ctx.beginPath();
  ctx.arc(komX(g.x) + u.kom / 2, komY(g.y) + u.kom / 2, u.kom * 0.32, 0, Math.PI * 2);
  ctx.fillStyle = KOLORY.gracz;
  ctx.fill();
  ctx.lineWidth = gruboscObrysu(u.kom);
  ctx.strokeStyle = KOLORY.obrys;
  ctx.stroke();

  // Iskry po podniesieniu klucza
  ctx.fillStyle = KOLORY.iskra;
  for (const i of anim.iskry) {
    const st = stanIskry(i, czas);
    if (!st) continue;
    zKryciem(ctx, st.alfa, () => kolo(ctx, komX(st.x) + u.kom / 2, komY(st.y) + u.kom / 2, Math.max(1.5, u.kom * 0.05)));
  }

  // Rozbłysk przy drzwiach po ukończeniu poziomu
  if (anim.rozblysk != null) {
    const b = rozblysk(anim.rozblysk, czas);
    if (b) {
      zKryciem(ctx, b.alfa, () => {
        ctx.beginPath();
        ctx.arc(komX(stan.wyjscie.x) + u.kom / 2, komY(stan.wyjscie.y) + u.kom / 2, u.kom * (0.5 + 2.5 * b.promien), 0, Math.PI * 2);
        ctx.strokeStyle = KOLORY.rozblysk;
        ctx.lineWidth = Math.max(2, u.kom * 0.15) * (1 - b.promien * 0.5);
        ctx.stroke();
      });
    }
  }
}

/** Cała plansza bez animacji — ograniczony ruch i zgodność z wcześniejszym API. */
export function rysuj(ctx, stan, szerokoscCss, wysokoscCss, tekstury) {
  if (!stan) return;
  rysujPlansze(ctx, stan, szerokoscCss, wysokoscCss, tekstury);
  rysujKlatke(ctx, stan, szerokoscCss, wysokoscCss, animStatyczna(stan), 0);
}

/** Klucz: kółko (główka) + trzon z ząbkami, z ciemnym obrysem pod spodem; `blysk` 0..1 — pas światła. */
function rysujKlucz(ctx, x, y, kom, blysk) {
  const s = kom;
  const cy = y + s / 2;
  const linia = Math.max(1.5, s * 0.1);
  ctx.beginPath();
  ctx.arc(x + s * 0.32, cy, s * 0.14, 0, Math.PI * 2);
  ctx.moveTo(x + s * 0.46, cy);
  ctx.lineTo(x + s * 0.8, cy);
  ctx.moveTo(x + s * 0.7, cy);
  ctx.lineTo(x + s * 0.7, cy + s * 0.14);
  ctx.moveTo(x + s * 0.8, cy);
  ctx.lineTo(x + s * 0.8, cy + s * 0.14);
  ctx.lineCap = 'round';
  ctx.strokeStyle = KOLORY.obrys;
  ctx.lineWidth = linia + 2 * gruboscObrysu(s);
  ctx.stroke();
  ctx.strokeStyle = KOLORY.klucz;
  ctx.lineWidth = linia;
  ctx.stroke();
  if (blysk != null) {
    const bx = x + s * (0.15 + 0.7 * blysk);
    zKryciem(ctx, 0.8, () => {
      ctx.beginPath();
      ctx.moveTo(bx, cy - s * 0.2);
      ctx.lineTo(bx + s * 0.08, cy + s * 0.2);
      ctx.strokeStyle = KOLORY.blysk;
      ctx.lineWidth = Math.max(1, s * 0.06);
      ctx.stroke();
    });
  }
}

/**
 * Drzwi: zamknięte = pełny prostokąt z dziurką od klucza; otwarte = pusta rama z otwartym skrzydłem
 * i pulsującą poświatą (`puls` 0..1). Z obrysem.
 */
function rysujDrzwi(ctx, x, y, kom, otwarte, puls) {
  const s = kom;
  const l = x + s * 0.22;
  const t = y + s * 0.14;
  const w = s * 0.56;
  const h = s * 0.72;
  const rama = Math.max(1.5, s * 0.08);
  const obrys = gruboscObrysu(s);
  if (!otwarte) {
    ctx.fillStyle = KOLORY.drzwiZamkniete;
    ctx.fillRect(l, t, w, h);
    ctx.lineWidth = obrys;
    ctx.strokeStyle = KOLORY.obrys;
    ctx.strokeRect(l, t, w, h);
    ctx.fillStyle = KOLORY.mgla;
    ctx.beginPath();
    ctx.arc(l + w / 2, t + h * 0.45, s * 0.07, 0, Math.PI * 2);
    ctx.fill();
    ctx.fillRect(l + w / 2 - s * 0.03, t + h * 0.45, s * 0.06, h * 0.25);
  } else {
    if (puls > 0) {
      zKryciem(ctx, 0.15 + 0.25 * puls, () => {
        ctx.fillStyle = KOLORY.drzwiOtwarte;
        ctx.fillRect(l - s * 0.08, t - s * 0.08, w + s * 0.16, h + s * 0.16);
      });
    }
    ctx.strokeStyle = KOLORY.obrys;
    ctx.lineWidth = rama + 2 * obrys;
    ctx.strokeRect(l, t, w, h);
    ctx.strokeStyle = KOLORY.drzwiOtwarte;
    ctx.lineWidth = rama;
    ctx.strokeRect(l, t, w, h);
    ctx.beginPath();
    ctx.moveTo(l, t);
    ctx.lineTo(l + w * 0.45, t + h * 0.12);
    ctx.lineTo(l + w * 0.45, t + h * 0.88);
    ctx.lineTo(l, t + h);
    ctx.closePath();
    ctx.fillStyle = KOLORY.drzwiOtwarte;
    ctx.fill();
    ctx.lineWidth = obrys;
    ctx.strokeStyle = KOLORY.obrys;
    ctx.stroke();
  }
}
```
